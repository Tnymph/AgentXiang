现在我们就来证明这个结论首先当 N 等于一的时候一阶方阵 A 已经是上三角矩阵了当 N 大于一的时候我们假设 N 减一阶的方阵可以经过有限次倍加行变换化为上三角矩阵以此为基础下面来证明 N 阶方阵可以经过有限次被加行变换化为上三角矩阵
于是根据数学归纳法原理也就是多米诺骨牌效应就可以知道任何一个 N 阶方阵 A 都可以经过有限次的倍加行变换化为上三角矩阵
这里 N 等于一的时候
A 已经是上三角矩阵我们可以说它经过零次被加行变换化为上三角矩阵所以这个结论对于 N 等于一成立
当 N 大于一的时候如果我们能够由这个结论对于 N 减一阶的方阵成立推出它对于 N 阶的方阵也成立
那么由 N 等于一的时候成立可以推出 N 等于二的时候成立由 N 等于二的时候成立可以推出 N 等于三的时候成立以此类推就可以得到这个结论对于任意 N阶的方阵都成立
所以要完成这个证明就只剩下由这个结论对于 N 减一阶的方针成立去推它对于 N 阶的方阵也成立

要回答这个问题我们从 N 等于一开始我们规定有一个数 A 一一构成的一阶行列式就是这个数 A 一一本身以后对于这样的一阶行列式我们不再写两边的这个竖线以免与绝对值的旗号混淆对于二阶行列式我们已经用对角线法则定义过了

可以推广到任意二阶以上的情形我们可以这样做先取出这里的 A 一一再把它所在的行河列化去剩下来的 A 二二称为 A 一一的原子式前面乘以负一的一加一次方得到的这一部分称为 A 一一的代数语子式接下来取出这里的 A 一二把它所在的行和列去掉
剩下来的 A 二一称为 A 一二的鱼子式前面乘以负一的一加二次方得到的结果称为 A 一二的代数语子式把 A 一一和他的代数与子式的乘积加上 A 一二和他的代数语子式的乘积作为这个二阶行列式的定义注意这里负一的指数一加一对应这个 Anum threads: 12

一般的当整数 N 大于等于二的时候为了定义 N阶 行列是
假设 N 减一阶行列式已经定义好了我们以此为基础来定义 N 阶的行列式先把 A 一一所在的行和列去掉剩下来的这些元素构成这样一个 N 减一阶的行列式称为 A 一一的原子式即为大写的 M 一一前面乘以负一的一加一次方得到的结果
称为 A 一一的代数语子式即为大写的 A 一一
再把 A 一二所在的含河列去掉剩下来的元素构成这样一个 N 减一阶的行列式称为 A 一二的原子式即为大写的 M 一二在它的前面乘以负一的一加二次方得到的结果称为 A 一二的代数与子式即为大写的 A 一二以此类推最后把 A 一 N 所在的含河列去掉
剩下来的这些元素构成一个 N 减一阶的行列式称为 A 一 N 的原子式即为大写的 M 一 N 在它的前面乘以负一的一加 N 次方得到的结果称为 A 一 N 的代数与子式即为大写的 A 一 N 把这个 N 阶行列式中的第一行的各个元素和他们的代数与子式对应相乘
得到的成绩加在一起就是这个 N 阶行列式的定义
现在我们把 N 阶行列式的定义完整的叙述一下当 N 等于一的时候由一个数 A 一一构成的这个一阶行列式就等于 A 一一这个数本身当 N 大于等于二的时候假设 N 减一阶的行列式以定义那么 N阶行列式等于它第一行各个元素与对应的属于子式的乘积之和
这里的 M 一一 M 一二一直到 M 一 N 都是 N 减一阶的行列式它们分别是 A 一一 A 一二一直到 A 一 N 的鱼子式
这样一来我们由一阶行列式就可以得到二阶行列式由二阶行列式就可以得到三阶行列式以此类推 N 阶行列式对于任意的正整数 N 都有定义了
特别的在这个 N阶 行列式中它的主对角线元素下方的元素全都是零我们把这样的 N阶 行列式称为 N阶 的上三角形行列式
